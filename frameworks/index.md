# Frameworks

The course builds four frameworks, one after another. Each tests a different link in the chain from question to gap: FARES tests your research question, PRISMA documents how you searched, MERC tests the papers you read, and TIPS tests the gap that connects them.

| Framework | What it's for | Introduced | Used in |
| :---- | :---- | :---- | :---- |
| [FARES]({{ '/frameworks/fares/' | relative_url }}) | Evaluating a research question | Class 2 ({% include classdate.html n="2" fmt="short" %}) | Checkpoint 1; proposal section 2 |
| [PRISMA]({{ '/frameworks/prisma/' | relative_url }}) | Documenting a literature search | Class 3 ({% include classdate.html n="3" fmt="short" %}) | Checkpoint 1, part 2 |
| [MERC]({{ '/frameworks/merc/' | relative_url }}) | Critical analysis of papers | Class 4 ({% include classdate.html n="4" fmt="short" %}) | Checkpoint 2, part 1; proposal section 3 |
| [TIPS]({{ '/frameworks/tips/' | relative_url }}) | Evaluating research gaps | Class 5 ({% include classdate.html n="5" fmt="short" %}) | Checkpoint 2, part 3; proposal section 3 |
