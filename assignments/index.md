## For all assignments

- Write in Google Docs and share a View link in BrightSpace, so the version history is visible.
- If you used AI tools, add an AI usage statement as described in the [AI policy]({{ '/ai-policy/' | relative_url }}).
- Before you review classmates' work, read the [peer review guidelines]({{ '/frameworks/peer-review/' | relative_url }}).
